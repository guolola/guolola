## ✧ 关于我 · About me

Hi，我是 **guolola**。喜欢把模糊的想法，慢慢变成看得见、讲得清、跑得起来的东西。

- **正在做**：面向软件工程教学的 AI 辅助实验平台。
- **关注方向**：需求分析、UML 建模，以及从模型到前端原型的完整链路。
- **日常工具**：JavaScript、Vue、HTML / CSS、Node.js。
- **代码之外**：喜欢二次元，也喜欢《鸣潮》里的达妮娅。给代码留一点认真，也给喜欢的角色留一个位置。
